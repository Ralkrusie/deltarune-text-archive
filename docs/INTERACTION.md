# 灵魂互动：当前版本

2026-10-26。此部分按用户要求暂告一段落；后续优先推进台词查看与还原模式，不继续扩展彩蛋玩法。它是可关闭的站点互动，不是游戏还原验收样例。

## 操作

| 操作 | 行为 |
|---|---|
| 点击灵魂，或单独按下并松开左/右 Shift | 红 → 黄 → 绿 → 橙 → 紫循环，切换主题、播放变色声和闪光 |
| 鼠标拖动 | 移动任意颜色的灵魂；紫魂松手吸附最近分隔线 |
| 点击书台原位置 | 灵魂飞回书台 |
| 右键灵魂 | 约 0.6 秒内灵魂与视角一起回顶部，颜色不变 |
| 设置中关闭灵魂互动 | 隐藏灵魂，恢复默认蓝色主题 |

移动及键盘玩法限桌面鼠标设备。输入框、弹窗内不触发玩法；Shift 与其他键、鼠标、滚轮组合时不切换，Shift+方向键留给文本选择。关闭、换色、失焦等操作取消蓄力和临时动作，避免回来后补发。动画只在需要时运行。

## 各颜色玩法

| 颜色 | 当前行为 |
|---|---|
| 红 | 方向键自由移动，速度 360px/s；屏幕边缘接管上下滚页 |
| 黄 | 移动转向；Z 小弹，按住约 0.67 秒后松开发大弹；原版粒子、蓄力脉动和音效 |
| 绿 | 方向键立即转斧；同一方向保持 1 秒后开始移动，松开或换向重新计时 |
| 橙 | 移动转向；按住 Z 蓄力、松开冲刺，轻点也能短冲，约 0.53 秒满蓄；金色轮廓填充、白色脉动；仅冲刺产生拖影 |
| 紫 | 使用页面已有的主题分隔线；横线上左右走、上下换线，竖线上上下走、左右换列，端点连接前后记录 |

紫魂首次从书台按 ↓ 先到搜索区上边线，再按到下边线。滚轮滚动后可挂在吸顶栏下边，再按 ↓ 进入当前屏幕内最近的内容分隔线；竖线落在可见部分。没有可见线才寻找屏幕下方下一根。横纵排、搜索结果和窗口变化后重新定位；不铺新线、不走灰色卡片框、不跨结果分页构造轨道。只有一种语言、没有内容分隔线时仍需滚轮浏览。

## 已确认的视觉参数

- 灵魂 1.5 倍，书台 4 倍；保持当前书台位置。黄橙默认朝下，移动时转向。
- 切换闪光最终为 **0.45 秒**：本体闪白，两层同形彩色光影扩散至约 **2.3 / 3.2 倍**后淡出。像素边缘不模糊，不闪全屏。
- 连续切换重启闪光，不叠加；刷新、设置开关、召回不触发。关闭、召回、失焦会清除闪光；系统减少动画偏好下跳过闪光、立即完成召回。
- 变色音效使用原始 `snd_great_shine`，音高 0.8。Spamton NEO 另有叠加声音，本站采用两场景共有的这一层。
- 橙魂采用原轮廓和粒子原点；金色填充随朝向旋转，朝下时由上往下。拖影画布按实际 CSS 尺寸绘制，避免滚动条导致偏左。

## 来源与适配边界

黄魂根据 CH2 普通黄魂与子弹源码；绿魂斧子来自 CH4；橙紫魂根据 CH5 运动/绘图对象。原始导出及来源保留 local，发布映射见 [资源约定](ASSETS.md)，准备方法见 [构建说明](BUILDING.md)。

网页适配包括全方向移动/转向、绿魂延迟移动、紫魂沿网页横竖线行进和五色统一切换闪光。未实现敌人、碰撞伤害、黄魂 Supercharge、橙魂关卡机关或游戏场景完整重放；未用游戏录像逐帧/逐采样比对，不能称为完全复刻。还原模式应独立验收。
