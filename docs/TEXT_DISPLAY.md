# 源码／简洁显示与网站文本包 v1

## 职责

`web/text.js` 是浏览器与 Node 共用的无依赖模块，输入为某章某语言的原始字符串；不读取旧项目、不查询本机路径或游戏、不根据台词猜角色。`format(raw, chapter)` 返回 raw、source、plain、state、issues、tokens。源码模式不运行文本替换：raw 完整保留，source 只将换行／Tab 等不可见字符转成可见转义；整条复制的规则见下文。

简洁模式是基于 writer 常见语法的阅读投影，不是游戏还原，也不能证明所有语言表项都由 writer 消费。没有用法信息时，无法从字符串推断实际消费者或动态内容。

## 简洁规则

- 常见表情、头像切换、颜色、声音、运动与暂停指令不作为正文显示；原文与 token 中仍完整保留。
- 语法按章区分：\a 为第 1 章，\m 从第 2 章，\O 从第 3 章，\V／\v 为第 5 章。规则依据各章 obj_writer Draw 的指令分支；运行时不读取游戏源码。未确认的片段原样保留并标记，而非任意吞掉三个字符。
- `&`、`#`、实际换行作为换行；`|` 为空格、Tab 为四空格。页面保留显式换行并按容器宽度自动折行；搜索投影把空白折叠为单个空格。
- 反引号优先转义紧随的字符；例如 `` `% `` 显示字面百分号，`` `~1 `` 不作为参数。
- 尾部消息结束标记隐藏；内部 `/`、`%` 保留，数字紧邻的末尾百分号保留。这是为无消费者信息的菜单／正文提供保守阅读，不能据此声称全部符合游戏执行。尾部符号或 `&/#/|` 本身属于字面内容的场景，仍需用法证据或源码模式核对。
- `~N` 显示为 `〔参数 ~N〕`，不猜名字、数值或借其他语言替换。
- `\O0` 显示 `〔艺术字 0〕`，`\I2` 显示 `〔图标 2〕`，`\m1` 显示 `〔行内头像 1〕`。这些是槽位，不是资源 ID 或角色 ID。
- `\C4` 显示 `〔选择指令 \C4〕`，不凭这个数字推断选项文本或上下文分支。
- missing（null）、empty（空串）、control-only（只剩控制与空白）、text 分开。UI 必须显示状态，不能把控制串条目当读取失败或删掉。
- 未知／不完整控制片段保留原样并记录 unknown-sequence。正文中的星号不统一删除；没有消费上下文，不能把所有星号当不可见装饰。

`\m` 行内头像不等于 smallface 对象消息。当前保留 smallface 的独立文本 key；主消息关联、人物和贴图仍待属性接入。艺术字文字映射、图片素材和动态实参尚未接入，当前显示占位。

返回值是字符串而非 HTML；页面用 textContent（或严格 HTML 转义）插入。预览报告对源文本、key 和标注全部做 HTML 转义。

## 最小网站数据

`build_site_data.py` 验证文本构建 manifest 的摘要后生成 `build/site-data/manifest.json` 和 ch1..ch5.json。

```json
{
  "schema": 1,
  "chapter": 1,
  "languages": ["en", "ja", "zh_default", "zh_names", "zh_recruitable"],
  "strings": ["* Example./", "* 示例。/"],
  "rows": [["synthetic_example", 0, null, 1, 1, 1]]
}
```

同章完全相同的字符串共享存储，key 与语言列仍各自保留；这不等于合并角色、用法或跨章台词。null 表示缺失，空串作为普通字典项保存。`decodeRow` 还原按字段命名的对象。

不重复存储源码转义字符串、简洁字符串、搜索索引或 tokens；显示和搜索模块按需计算并缓存。网站文本按章分包，所选章节由搜索 Worker 加载。包内不包含绝对路径、来源记录、静态归因详情、运行日志、字体或图片。

## 验证范围

合成测试检查转义、缺失、控制串、注入文本作为普通字符串、参数图片占位和跨章差异；真实样本检查具体显示结果。全量检查逐条解码还原语言字段，并核验 token 原片段拼接等于原串。检查入口为 `node tests/text_display.cjs` 和 `node tools/check_display.cjs`；后者需要已导入的真实文本。数据完整性通过不等于每条简洁文本语义均已人工验收。

## 可选源码位置

章数据增加 `source_files` 文件名字典；每行第 7 项为 `[[fileIndex, line], ...]`，无位置为空数组。解码器兼容没有这两项的旧文本包。网站 manifest kind 为 `viewer-site-data`。文件名限定 gml_*.gml，无绝对路径；位置来自有快照绑定的独立映射，链接由前端生成。当前映射从旧格式 SQLite 数据库迁移并用 GML 核验，见 [构建说明](BUILDING.md)；正式构建不读取旧数据库。它仅供跳转，不代表运行覆盖或已确认角色。

## 复制

页面仅保留“复制 key”和“复制本条”；单语言正文可用鼠标选择复制。整条复制入口使用 `actions.js`：源码复制采用 `sourceText` 可见转义，格式为 key、空行、所选语言块；中文智能原串相同才合组。简洁复制折行为单行，图片／参数占位保持。原始数据本身保持不变。

## 句首星号阅读排版

`readingLines(plain)` 只提供逐行位置、句首半角／全角星号和正文起点，保留 UTF-16 原偏移以复用搜索高亮。有星号段落的后续行与正文对齐，空行结束该段；没有星号的文本与行内星号不套用。CSS 使用悬挂缩进，原有空白字符保留在 DOM 顺序中，仅折叠缩进的视觉宽度；不修改 format 的 plain、source、raw 和复制／搜索投影。

该排版不额外插入空格或换行，鼠标选择复制保留正文顺序。源码模式不使用星号分列。

## 检索范围与展示

章节状态为去重、升序的章节数组。URL 使用 `ch=1,3` 表示组合；`ch=0` 和未指定表示全部，旧链接 `ch=4` 继续有效。点击“全部”恢复五章；全部状态点击某章进入该章，再点击其他章节增减选择，至少保留一章。同 key 跨章仍分别展示。

搜索固定覆盖英文、日文、三种中文人名译法和 key；显示语言、中文译法只决定展示和整条复制内容，切换时保留结果与页码。未显示的语言也可能命中，因此可见文本不一定含有高亮；切换到命中语言即可查看。检索同时使用源码、简洁和原串投影，不因当前显示模式改变匹配范围。

上下文窗口使用浏览器原生右下角双向缩放，限制在视口内，当前页面内再次打开保留尺寸，刷新恢复默认。内容宽度不足 650px 时，分支改为单列。缩放结束不视为点击遮罩，关闭按钮和普通遮罩点击保持有效。
